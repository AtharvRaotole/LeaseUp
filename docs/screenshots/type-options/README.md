# Typography pairing prototypes (Oct 2025)

Three pairings compared on landing and report at 1440px and 390px:

| Pairing | Sans | Display |
| --- | --- | --- |
| `schibsted` | Schibsted Grotesk | Same (semibold) |
| `general-newsreader` | General Sans | Newsreader |
| `figtree` | Figtree | Same (semibold) |

**Winner: Schibsted Grotesk (sans-only).** Strong editorial character without a decorative serif, excellent rank and table legibility with proportional tabular figures, and a single-family system that keeps weight and CLS predictable.
