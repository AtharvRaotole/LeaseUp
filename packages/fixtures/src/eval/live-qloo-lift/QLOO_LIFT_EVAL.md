# Live Qloo lift evaluation

Headline numbers for LeaseUp product copy (committed in `aggregates.json`).

## Cohort metrics

| Metric | Value | Notes |
| --- | --- | --- |
| Raw Qloo P@10 | 0.54 | Same ATP presence panel; Qloo list order only |
| Chain size P@10 | 0.76 | Same pool sorted by national store count |
| Legacy 0.75/0.25 blend P@10 | 0.59 | Deprecated ranking prior |
| Same-size tier AUC | 0.672 | 95% CI [0.650, 0.693] |
| Logistic blend P@10 | 0.82 | +6.5 pp vs chain; 95% CI [3.2, 9.5] pp |

## Findings

- Heatmap features did not improve ranking lift in offline tests.
- Fixed 10 km presence scoring saturates in dense trade areas; adaptive radius is used for strict eval and backtests.
- Qloo affinity partly encodes brands that already operate in the trade area. Same-size tier AUC and the logistic companion blend are the honest headline metrics.
